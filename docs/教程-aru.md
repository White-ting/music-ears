# 在 Aru 里和 TA 一起听歌：黑胶播放器搭建教程

> 写给没碰过命令行的人。一步一步跟着做，第一次装大约要 1～2 小时（大部分时间在等下载）。
> 卡住了就截图问人（**截图前先遮住口令**）。

---

## 这是什么

装好以后：

- 你在 Aru 里打开一个**黑胶唱片播放器**，能放网易云的歌：唱片在转、歌词跟着走，登录网易云还能看到自己的歌单。
- 点「**一起听**」，Aru 里的 TA 就知道你放到哪一句了。
- TA 读的是一张**乐谱卡**：电脑把歌拆开量出来的调、拍速、和弦、每句的旋律、换气、长音，再加上模型听出来的感觉。TA 听不见声音，但能"看懂"这首歌，跟你聊到具体哪一句。
- TA 还能**给你点歌**（排进下一首，屏幕上冒出 TA 想说的话），也能**帮播放器换外观**。

```
你的手机（Aru）
   ├─ 网页应用：黑胶播放器（你放歌、点一起听）
   └─ MCP：给 TA 的工具（搜歌、拆歌、读卡、一起听到哪了、点歌、换外观）
            ↓  都经过 Cloudflare 隧道
你的电脑：music-ears（播放器 + 拆歌 + 乐谱卡，数据都在这台电脑上）
```

音乐由你的手机直接从网易云取，不经过、也不保存在 music-ears 里。

---

## 需要准备

| 东西 | 说明 |
|---|---|
| 一台常开的电脑 | Windows 10 / 11，或者 Mac。播放器和拆歌都跑在这台电脑上，**用的时候电脑要开着** |
| 硬盘空间 | 装好大约 4GB；之后每拆一首歌约 150MB（可以清，见最后「省地方」） |
| iPhone + Aru | 要能用 MCP 和「应用与连接」 |
| Cloudflare 账号 + 一个域名 + 一条隧道 | 手机在外面也能连到电脑要用。**已经给 Aru Host（或 knock 守门人）搭过隧道的，直接用那条**，第 10 步只加一个子域名 |
| 网易云账号（可选） | 不登录也能搜歌、放免费的歌；想看自己的歌单、放会员歌要登录（会员歌要会员号） |
| 模型钥匙（可选） | 不配也能出乐谱卡，只是少了"模型听"的那部分。见「模型钥匙」 |

> 下面以 **Windows** 为主写；Mac 不一样的地方单独标了「**Mac**」。想放在云服务器（VPS）上的，看最后「放在 VPS 上」。

### 实测情况（2026-10-20）

| 电脑 | 情况 |
|---|---|
| **Mac（Apple 芯片）** | ✅ 照这份教程在一个新文件夹里从头走通：装库、检查、设口令、双击启动、拆歌、一起听。装库约 2 分钟（网快、底子已下过），拆一首 3 分钟的歌约 3 分钟 |
| **Linux（Ubuntu 24.04，当成 VPS 测）** | ✅ 从零装通：装 Docker、装库约 21 分钟、检查、拆同一首歌约 4 分钟（卡跟 Mac 上一模一样）、播放器和 MCP 都能用。不用 sudo 也能跑（要先把自己加进 docker 组） |
| **Windows** | ⚠️ **还没在真的 Windows 上跑过**。中文、路径这些按 Windows 的规矩改过，但没实测，可能会卡。卡在哪一步截图来问 |
| Mac（Intel 芯片） | 没测，原理上跟 Apple 芯片一样 |

都没测过的：Aru 里接 MCP、当网页应用打开（第 11、12 步）。

## 第 1 步：装 Docker Desktop

拆歌时量旋律、分人声伴奏的那部分程序装在 Docker 里，不会弄乱你的电脑。

1. 打开 <https://www.docker.com/products/docker-desktop/>，下载 Windows 版，双击安装，一路默认。
   中途让你装 **WSL** 就同意，装完按提示**重启电脑**。
2. 重启后打开 Docker Desktop（可以跳过登录），等左下角变成绿色的 **Engine running**。
3. **在国内要做这一步**：右上角齿轮（Settings）→ **Docker Engine**，右边是一段文字，在最外面那对大括号里面加一行（注意上一行末尾要有逗号）：

   ```
   "registry-mirrors": ["https://docker.1ms.run"]
   ```

   点 **Apply & restart**。

> **Mac**：同一个网址下载 Mac 版（看清是 Apple 芯片还是 Intel），拖进「应用程序」打开。第 3 步一样做。

**成了的样子**：Docker Desktop 左下角是绿色的 Engine running。以后每次用之前，Docker Desktop 要开着（可以在它设置里勾「开机自动启动」）。

---

## 第 2 步：装 Python

1. 打开 <https://www.python.org/downloads/>，下载最新的 Python 3。
2. 安装第一页**一定要勾上最下面的 "Add python.exe to PATH"**，再点 Install Now。

> **Mac**：先打开「终端」，输入 `python3 --version` 回车：
> - 显示 `Python 3.x.x` 就有了，跳过这步；
> - 弹出窗口说要安装"命令行开发者工具"，点「安装」，等它装完（几分钟到十几分钟）再输入一次，能显示版本就行。不想装这个，也可以从上面的网址下载 Mac 版 Python 装上。

---

## 第 3 步：放好 music-ears

1. 把压缩包里的 **music-ears** 文件夹，复制到一个**路径全是英文、没有空格**的地方，比如 `D:\music-ears`。
   **别放在桌面、"文档"或者带中文名的文件夹里**，路径里有中文或空格，后面几步容易出错。
2. 打开这个文件夹，里面应该能看到 `music-ears`、`src`、`web`、`requirements.txt` 这些。

> **Mac**：放在 `~/music-ears`（在访达里按 Command+Shift+H 打开个人文件夹，拖进去）。

---

## 第 4 步：在这个文件夹里打开命令窗口

1. 打开 `D:\music-ears` 文件夹，在上面的**地址栏**里点一下，把路径删掉，输入 `powershell`，回车。
2. 会打开一个蓝色（或黑色）窗口，开头写着 `PS D:\music-ears>`，说明位置对了。

下面所有命令都在这个窗口里**粘贴、回车**（在窗口里点右键就是粘贴）。等它跑完、重新出现 `PS D:\music-ears>` 再粘下一条。

> **Mac**：打开「终端」，输入 `cd ~/music-ears` 回车。

---

## 第 5 步：装测量要的库（最久的一步）

粘贴这一整行，回车：

```
docker run --rm -v "${PWD}:/w" python:3.12-slim sh -c "python -m venv --copies /w/venv && /w/venv/bin/pip install -r /w/requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple --extra-index-url https://download.pytorch.org/whl/cpu"
```

- 第一次会先下载一个约 50MB 的底子，再装 PyTorch 等库，大约 1～2GB，**耐心等它跑完**，重新出现 `PS D:\music-ears>` 才算完。
- 中途断了、报网络错误，就再粘一次这条，装好的不会重装。

> **Mac**：用这条（区别只在开头的 `"$PWD"`）：
>
> ```
> docker run --rm -v "$PWD:/w" python:3.12-slim sh -c "python -m venv --copies /w/venv && /w/venv/bin/pip install -r /w/requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple --extra-index-url https://download.pytorch.org/whl/cpu"
> ```

---

## 第 6 步：检查一遍

```
python music-ears doctor
```

> **Mac**：`python3 music-ears doctor`（下面所有 `python` 在 Mac 上都写 `python3`）。

它会一行一行查：

- `✓` 是好的；
- `！` 是可选的（比如没配钥匙、没登录网易云），不影响用；
- `✗` 是必须处理的，下面会写怎么补。

**成了的样子**：最后一行是"没问题，可以用了"。

---

## 第 7 步：设一个口令

手机要从外面连进来，必须有口令，不然谁都能用你的播放器。

1. 生成一个口令（在命令窗口里粘贴、回车）：

   ```
   python -c "import secrets; print(secrets.token_hex(16))"
   ```

   会打印一串 32 个字母数字。**这串就是口令：别发给别人、别截图。** 先复制到记事本里放着，后面要用三次。

2. 打开设置文件夹：在资源管理器地址栏输入 `%USERPROFILE%\.config\music-ears`，回车。
   提示不存在，就先进 `%USERPROFILE%`，新建文件夹 `.config`，再在里面新建 `music-ears`。

3. 在这个文件夹里新建一个文本文件，改名成 `config.json`。
   - 先在资源管理器「查看」里勾上「文件扩展名」，确认名字是 `config.json`，不是 `config.json.txt`。
4. 用记事本打开它，写这一行（把中文换成你的口令，引号别删），保存：

   ```
   { "serve": { "token": "这里换成你的口令" } }
   ```

> **Mac**：设置文件夹是 `~/.config/music-ears`。在终端里 `mkdir -p ~/.config/music-ears && open ~/.config/music-ears` 就打开了，用「文本编辑」新建纯文本文件存成 `config.json`（格式 → 制作纯文本）。

---

## 第 8 步：打开播放器

1. 双击 music-ears 文件夹里的 **`启动播放器.bat`**。
   会打开一个黑窗口，出现 `黑胶播放器：http://127.0.0.1:8790/?key=口令` 就开好了。
   **这个黑窗口要一直开着**，关了播放器就停了。以后每次开电脑想用，都双击一次它。
2. 在电脑浏览器里打开（把"你的口令"换掉）：

   ```
   http://127.0.0.1:8790/?key=你的口令
   ```

   能看到黑胶播放器就对了。
3. **登录网易云（可选，建议做）**：右上角进歌单 → 「扫码登录」→ 用手机上的**网易云音乐 App** 扫电脑屏幕上的码，在手机上点确认。登录信息只存在这台电脑上。
   - 要在电脑上扫，所以这步在电脑浏览器里做。

> **Mac**：双击 **`启动播放器.command`**。第一次如果提示"无法验证开发者"，就右键它 → 打开 → 再点「打开」。

**成了的样子**：播放器里能搜到歌、放出声音；登录了的话，歌单页有你自己的歌单。

---

## 第 9 步：拆第一首歌

一起听要先有这首歌的乐谱卡。先拆一首试试：

1. 播放器里搜一首歌，点歌右边的「⋯」→「**拆乐谱卡**」。
2. 屏幕上方会浮出一条进度（歌名、拆了几分钟 / 预计几分钟）。
   - 一首 4 分钟的歌大约 8 分钟。
   - **第一次会先下载约 100MB 的模型**，会更久。
   - 一次只拆一首，多点的会排队。关掉播放页、刷新页面，进度都还在。
3. 拆好了会提醒你。

> 拆失败了：看第 8 步那个黑窗口里最后几行写了什么，截图来问；或者在命令窗口跑一次 `python music-ears doctor` 看哪项是 ✗。
> 会员歌没登录会员号拆不了（拿不到完整音频）。

---

## 第 10 步：给播放器一个手机能打开的地址

手机上的 Aru 连不到你电脑的 `127.0.0.1`，要经 Cloudflare 隧道给它一个 HTTPS 地址。

**已经有隧道的（给 Aru Host 或 knock 建过）：**

1. 打开 Cloudflare 后台 → **Zero Trust** → **网络 Networks** → **Tunnels**，点你那条隧道的名字（旧界面是右边的 Configure / 编辑）。
2. 找到 **公共主机名（Public Hostname）** → **添加（Add a public hostname）**。
3. 填：
   - **子域名**：`ears`（下面都用 `ears` 举例）
   - **域**：选你的域名
   - **服务**：类型选 `HTTP`，URL 填 `localhost:8790`（**是 http，不是 https**）
4. 保存。等一两分钟，用**手机浏览器**打开：

   ```
   https://ears.你的域名/?key=你的口令
   ```

   看到播放器就通了。不带 `?key=` 打开会看到"要口令"，这是对的。

**还没有隧道的**：照 Cloudflare 后台 → Zero Trust → 网络 → Tunnels → 创建隧道 → 选 Cloudflared → 按页面给的命令在电脑上装好（Windows 选 64 位 .msi，装完用管理员身份运行页面给的那条 `cloudflared.exe service install …`）→ 再按上面第 2～4 步加公共主机名。域名要先交给 Cloudflare 管（在 Cloudflare 添加站点，照提示去域名注册商改 NS）。

> ⚠️ 域名、隧道要在**同一个** Cloudflare 账号里。Cloudflare 提示"去注册商改域名服务器（NS）"时，如果域名之前已经在用了，**先停下来问人**：多半是在另一个账号里又加了一次域名，照做会让域名整个断掉。

---

## 第 11 步：在 Aru 里接 MCP（给 TA 的工具）

总设置 → 连接 → MCP → 添加远程服务（界面名字可能略有不同，找"MCP""远程服务"）：

1. 类型选 **streamable HTTP**，地址填：

   ```
   https://ears.你的域名/mcp
   ```

2. 认证选 **Header**，加一行：
   - 名字：`Authorization`
   - 值：`Bearer 你的口令`（`Bearer` 和口令之间**一个空格**）

   找不到填 Header 的地方，就把地址写成 `https://ears.你的域名/mcp?key=你的口令`，效果一样。
3. 点测试连接。

**成了的样子**：能看到 11 个工具（`search_song`、`play`、`now_playing`、`set_skin` 等）。

4. 然后三处都要开，少一处 TA 就用不了：
   - **启用**这个服务器；
   - **允许你的协作者使用**；
   - 在对话的**工具箱里打开 MCP 开关**。

---

## 第 12 步：在 Aru 里接播放器（给你自己用）

总设置 → **应用与连接** → 连接网页应用：

1. 地址填：

   ```
   https://ears.你的域名/?key=你的口令
   ```

   凭据方式选"持续 URL token"或者直接带在地址里都行。
2. 装好以后，把它放进对话里的 **Apps 启动器**，或者协作者桌面、Dock，方便打开。

> 播放器是"网页应用"，**不是 HTML 卡片**：卡片是沙箱，连不了你的电脑，也记不住登录。

---

## 第 13 步：试一遍

按顺序试，哪一步不行就停下来看「排错」：

1. **搜歌**：问 TA「用 music-ears 搜一下《晴天》」→ TA 应该列出几首，带编号。
2. **点歌**：「给我点一首你喜欢的歌」→ 打开播放器，屏幕下方冒出 TA 说的话，那首排在下一首（什么都没放时直接开始放）。
3. **一起听**：给第 9 步拆好的那首点「⋯」→「一起听」，放一会儿，问 TA「我们听到哪了？」→ TA 应该说出正在唱的那句。
4. **换外观**：「把播放器换成樱花粉」→ 几秒内播放器变色。不喜欢就说「换回默认」。

都过了就装好了 🎉

## 平时怎么用

- **开电脑以后**：先开 Docker Desktop（勾了开机启动就不用管），再双击 `启动播放器.bat`。
- **一起听**：歌的「⋯」→「一起听」。拆过的直接开始；没拆过会问你要不要先拆，拆好再点一次。也可以提前「拆乐谱卡」攒着。
- **小唱片**：播放页左上角缩小，变成一个浮着的小唱片，能拖；点一下回来，长按冒出「关掉」和「一起听」。点唱片切换全屏歌词。
- **TA 点歌**：TA 用 `play` 点的歌默认排在下一首，不打断你。播放器没开着的话，半小时内打开都会收到。
- **换外观**：跟 TA 说想要什么样子就行，TA 会自己写一套换上。自己动手的话，在设置文件夹（第 7 步那个）里写一个 `skin.css`，能改什么见 music-ears 文件夹里的 `docs/skin.md`。
- **一起听的两种报法**：默认每次给 TA 看前后十秒的摘录；想让 TA 开头读整张卡、之后只报"第几句"，在 `config.json` 里加 `"listen_mode": "book"`：

  ```
  { "serve": { "token": "你的口令", "listen_mode": "book" } }
  ```

  改完关掉黑窗口、重新双击启动。

## 模型钥匙（可选）

不配钥匙也能出乐谱卡，有调、拍速、和弦、逐句旋律。配了钥匙，卡上多一段**模型听出来的感觉**（每段的情绪、唱法、乐器），还会请另一个模型复核。

| 钥匙 | 用来 | 去哪拿 |
|---|---|---|
| `dashscope.key` | 听（主要的那个） | 阿里云**百炼**控制台 → API-KEY → 创建。要实名认证，新用户有免费额度 |
| `gemini.key` | 复核 | Google AI Studio。国内要能连上 Google 才行，连不上就不配，没有影响 |

放法：

1. 在设置文件夹（第 7 步那个）里新建一个文件夹 `keys`。
2. 在 `keys` 里新建文本文件，**只写一行钥匙**，存成 `dashscope.key`（或 `gemini.key`）。注意别变成 `dashscope.key.txt`。
3. 再跑一次 `python music-ears doctor`，钥匙那几行变成 ✓ 就好了。

钥匙等于钱包：别发给任何人，别截图。

## 省地方

每拆一首歌约 150MB，大头是拆出来的人声、伴奏这些音轨。乐谱卡做好以后就用不上了，想省地方可以删：

- 打开 music-ears 文件夹里的 `cache`，每首歌一个文件夹（名字是数字编号）；
- 删掉里面的 **`stems` 文件夹**和 **`audio.wav`**，留下其他的（`card.md` 就是乐谱卡）。

一起听、读卡都不受影响。

## 排错

| 看到什么 | 多半是 |
|---|---|
| `python` 不是内部或外部命令 | 第 2 步没勾 "Add python.exe to PATH"：重装 Python，勾上 |
| `docker` 不是内部或外部命令 / Docker 连不上 | 先打开 Docker Desktop，等左下角变绿 |
| 第 5 步下载很慢、卡住、报网络错 | 检查第 1 步的镜像源；再粘一次那条命令；还不行就开着代理再试 |
| doctor 说 venv 里缺库 | 再跑一次第 5 步 |
| 双击 `启动播放器.bat` 一闪就没了 | 在命令窗口里打 `python music-ears serve` 看报什么错；多半是 Python 没装好，或者 `config.json` 格式不对（引号、括号少了） |
| 浏览器打开是"要口令" | 地址后面没带 `?key=口令`，或者口令抄错（跟 `config.json` 里的对一下） |
| 手机打不开 `https://ears.你的域名` | 黑窗口关了；隧道的服务写成了 https（会报 502）；电脑睡着了 |
| Aru 测试连接失败 | 黑窗口关了；地址少了 `/mcp`；Header 里 Bearer 后面的口令抄错 |
| 连上了，但 TA 说没有这个工具 | 第 11 步三个开关没开全 |
| TA 点的歌没出现 | 播放器没开着（打开后半小时内点的都会补上）；或者开着的不是 `ears.你的域名` 这个地址 |
| 「我们听到哪了」TA 说没在一起听 | 要在播放器里点「一起听」，光放歌不算；没拆过的歌要先拆 |
| 拆卡失败 | 看黑窗口最后几行；跑 doctor 看哪项是 ✗；会员歌要登录会员号 |
| 乐谱卡里的中文是乱码 | 用 `启动播放器.bat` 或 `python music-ears …` 跑，别直接双击 `music-ears` 文件 |
| 切回对话后歌停了 | Aru 里的网页切到后台可能不让出声：改在手机 Safari 里打开同一个播放器地址放歌，一起听照样算 |

## 口令和安全

- **口令等于钥匙**：带口令的地址、`config.json` 里的口令、Aru 里填的 Header，都别发到群里、别截图。
- 口令可能漏了：照第 7 步生成一串新的，改 `config.json`，关掉黑窗口重新启动，再把 Aru 里两处（MCP 和网页应用）的口令换掉。旧的立刻失效。
- 你的网易云登录、乐谱卡、外观都只存在你自己的电脑上。

---

## 放在 VPS 上（云服务器，选看）

放在一直开着的云服务器上，家里电脑就不用常开。Linux 服务器上实测能跑（见最上面「实测情况」），但有几件事要先知道：

**先想清楚的坑**

- **服务器在国外的话，网易云很多歌放不了、拆不了**：网易云按 IP 限制海外播放，服务器去要播放地址时会拿不到。**要用国内的服务器**（阿里云、腾讯云这类）。这一条我们没法在家里测，是网易云已知的限制。
- **内存至少 4GB**：拆歌时分人声伴奏那一步吃内存，2GB 的机器会被系统杀掉。
- **硬盘留 10GB 以上**：装好约 4GB，每首歌约 100～150MB。
- **扫码登录网易云要换个法子**：服务器没屏幕。先做完下面的隧道，在**电脑浏览器**里打开 `https://ears.你的域名/?key=口令`，用手机网易云扫电脑屏幕上的码。
- **没有双击启动**：要让它在后台一直跑（见下面第 5 步）。

**步骤**（下面的命令在服务器上用 SSH 登进去以后粘贴）

1. 装 Docker 和解压工具，把自己加进 docker 组：

   ```
   sudo apt-get update && sudo apt-get install -y docker.io unzip && sudo usermod -aG docker $USER
   ```

   装完**退出 SSH 再重新登录一次**，加组才生效。
2. 国内服务器给 Docker 加镜像源：

   ```
   echo '{"registry-mirrors": ["https://docker.1ms.run"]}' | sudo tee /etc/docker/daemon.json && sudo systemctl restart docker
   ```

3. 把压缩包传上去、解压，把 `music-ears` 文件夹放到 `~/music-ears`，`cd ~/music-ears`。然后照 **第 5 步的 Mac 那条命令**装库，照第 6 步跑 `python3 music-ears doctor`。
4. 照第 7 步设口令（Linux 跟 Mac 一样：`mkdir -p ~/.config/music-ears`，再用 `nano ~/.config/music-ears/config.json` 写那一行）。
5. 让它在后台一直跑，断开 SSH 也不停：

   ```
   sudo apt-get install -y tmux && tmux new -d -s ears "cd ~/music-ears && python3 music-ears serve"
   ```

   看它在不在：`tmux attach -t ears`（看完按 Ctrl+B 再按 D 退出来，**别按 Ctrl+C**，那会把它停掉）。服务器重启以后要再跑一次这条。
6. 隧道：在服务器上装 cloudflared（Cloudflare 后台建隧道时选 Linux，照页面给的命令装），公共主机名照第 10 步填 `localhost:8790`。**别在服务器防火墙上开 8790 端口**，只走隧道。
7. 后面第 9、11、12、13 步一样。

## 给带你装的 AI

如果你是 AI，正在照这份教程带一个人装 music-ears 并接进 Aru，请照下面做：

**先问清楚再开始**
- 先问：Windows、Mac 还是云服务器（VPS）；硬盘还剩多少；有没有 Cloudflare 账号、域名和在用的隧道（给 Aru Host 建过的那条就行）。没有域名或隧道的，第 10 步之前都能做（电脑上能用），第 10 步起要先把隧道建好。
- 已经装好、只差接 Aru 的，从第 10 步开始。

**一次只带一步**
- 说清楚这一步做什么、为什么，等对方说做好了、并且达到这一步写的"成了的样子"，再往下。不要一口气丢几步。
- 对方多半没用过命令行：命令要整段给，说清楚在哪个窗口粘贴、粘贴后按回车、等出现 `PS D:\music-ears>` 再继续。第 5 步要等很久，提醒对方别关窗口。
- 第 8 步的黑窗口要一直开着，要特别提醒。

**口令和钥匙：绝不进对话**
- 不向对方要口令、模型钥匙，不让对方把 `config.json` 的内容、带 `?key=` 的地址、Header 的值贴进对话或念出来。哪怕是为了帮忙核对也不要。
- 要看截图时，先提醒对方遮住口令（浏览器地址栏也要裁掉）。万一已经发出来了，告诉对方照「口令和安全」换一串新的。
- 要核对口令有没有抄错，让对方自己对比前四个、后四个字。

**界面对不上时别编**
- Docker、Cloudflare、Aru 的界面会改版，按钮名可能对不上。对不上时请对方截图（遮住口令）或描述屏幕上的字，照实际看到的带，不要凭印象编。
- Cloudflare 提示"去注册商改 NS"时，先停下来问清楚，别让对方照做。
- 不确定就说不确定。

**卡住了**
- 先对照「排错」那张表；拆歌、启动的问题先看黑窗口最后几行写了什么，再跑 `python music-ears doctor`。
