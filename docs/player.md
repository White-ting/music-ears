# 黑胶播放器和一起听

作者自己用的版本里，music-ears 外面还套了一个**黑胶播放器**，可以和 AI **一起听歌**：歌放到哪，AI 就"听"到哪。这个播放器长在作者私用的聊天前端里，暂时拆不出来单独放出。这份文档讲两件事：

1. 它用起来是什么样的，方便你想清楚要不要做；
2. 想在**你自己的前端**里做一个，music-ears 已经提供了哪些现成的东西，剩下的怎么接。

## 一、用起来什么样

**登录网易云（可选）**
在设置里点"网易云登录"，页面弹出二维码，用网易云音乐 App 扫码确认。登录信息只存在你自己的电脑上，有了它，会员歌也能放、也能拆。不登录也能用，只是会员歌只能听试听片段，拆的时候要自己附录音。

**放歌**
打开黑胶页，可以：
- 贴一个网易云歌曲链接；
- 从你的网易云歌单里挑（"我喜欢的音乐"和自建歌单）；
- 搜歌名、歌手。

每首右边的"⋯"可以"下一首播放""加到列表末尾"。

**播放页**
唱片在转，封面贴在唱片中间，背景是封面放大后的磨砂模糊；下面是进度条和播放、上一首、下一首。点一下唱片切到**全屏歌词**：当前句高亮放大，带翻译，可以手指上下滑，松手几秒后自动滚回唱到的那句。缩小后变成一个浮在聊天上的小唱片，点一下回到播放页。

**一起听**
在歌的"⋯"菜单，或者长按小唱片，选"一起听"：
1. 这首没拆过的话，后台先用 music-ears 拆，大约几分钟；拆过的直接拿缓存；
2. **乐谱卡送到 AI 那里之后，才开始放歌**，保证它先"看过"这首；
3. 放的过程中，页面每隔几秒把**播放到第几秒**告诉后端；你每次跟 AI 说话，后端都会附上一小段：现在放到哪一句，以及乐谱卡里**前后十秒**的内容（那几句的歌词、旋律、和弦、唱法）。AI 就能接着你听到的地方聊，比如"这里换气好急""副歌这个转音"。

## 二、自己做一个：music-ears 已经提供的

下面这些命令都输出 JSON（成功是 `{"ok": true, ...}`，失败是 `{"ok": false, "error": "..."}`），你的后端直接调命令、读输出就行。

**网易云登录**
```
music-ears login start          → {"key": "...", "url": "https://music.163.com/login?codekey=..."}
music-ears login check KEY      → {"code": 800|801|802|803, "msg": "..."}
music-ears login me             → {"me": 账号信息}
```
把 `url` 画成二维码给用户扫，每两秒 `check` 一次：801 等待扫码，802 已扫码待确认，803 成功（登录信息已自动存好），800 二维码过期。

**播放器要的数据**
```
music-ears vinyl playlists           → {"playlists": [...]}   用户的歌单
music-ears vinyl tracks 歌单编号      → {"tracks": [...]}      歌单里的歌
music-ears vinyl search 关键词        → {"songs": [...]}       搜索（已按 歌名 > 歌手 > 专辑 重排，没搜"翻唱/现场/伴奏"时把这些往后放）
music-ears vinyl url 歌曲编号         → {"src": "https://..."} 播放地址
music-ears vinyl lyric 歌曲编号       → {"lrc": "...", "tlyric": "..."}  LRC 歌词和翻译
```

**乐谱卡**
```
music-ears info 链接            → 歌名、歌手、是不是会员歌、能不能直接拿到音频、拆过没有
music-ears 链接                 → 拆，写卡（几分钟，适合放后台任务）
music-ears list --json          → 拆过的所有卡
music-ears card 文件夹名         → 打印某张卡的全文
```
卡存在 `cache/<歌曲编号>/card.md`（自己唱的是 `cache/rec-<编号>-<时间>/`）。

## 三、自己做一个：要你来写的

1. **播放**：用网页的 `<audio>` 直接放 `vinyl url` 给的地址。音频由用户的设备直接从网易云取，不经过你的服务器。地址大约二十分钟过期，播放报错时重新要一次、从原来的秒数接着放。
2. **封面**：有些环境（比如 iOS 里套壳的 App）直接加载网易云的图会一直挂着，可以让后端代取一下封面、存个缓存。
3. **把卡交给 AI**：拆完后把 `card.md` 的全文作为一条消息发给你的 AI，开头标明"这是乐谱卡，不是用户打的字"。
4. **一起听的位置**：
   - 前端定时（比如每 5 秒、以及暂停、拖动时）把 `{歌曲编号, 当前秒数, 在不在放}` 报给后端；
   - 后端在用户每次发消息时，从卡里找出带时间戳的那几行，取当前秒数前后十秒的部分，附在消息后面，比如：
     ```
     〔一起听：《歌名》放到 1:32（在放）。前后十秒的乐谱卡：
     [1:24] 歌词…  简谱…  和弦…
     [1:31] 歌词…  …〕
     ```
   - 注意：最后一句后面没有下一个时间戳，要按歌曲总长截断，不然会把结尾所有的音都算进最后一句。
5. **等卡再放**：点了"一起听"以后，先确认卡已经送到 AI 那里，再开始放，不然 AI 收到的位置信息对不上它手里的内容。
