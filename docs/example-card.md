# 乐谱卡长这样

下面是一张真卡的开头，歌是网易云上的《明知故犯》（Max李玄）。为了不搬运别人的歌词，**逐句里的歌词换成了「（第 N 句）」，听感里引用的字换成了「…」**，别的数字和描述都是 music-ears 原样写出来的。整张卡有 230 多行，覆盖整首歌。

## 没配钥匙时

加 `--no-listen`，或者没配"听"和"审查"的模型钥匙时，卡里只有脚本量的部分：调、拍速、音域、结构、逐句的旋律和和弦、长音、换气，没有〔听感〕和"整体听感"，开头会多一行说明：

```
- 没有听感：加了 --no-listen。这张卡只有脚本量的数字；配好钥匙后删掉这首的缓存文件夹再做一次，就有模型听的部分
```

## 给 AI 怎么用

把整张卡发给 AI，说一句"这是这首歌的乐谱卡"。它就能说出哪里转调、副歌怎么推上去、哪句换气急、哪个长音带颤音，跟你聊的时候能对着具体的那一句。一起听的时候，它还能拿到你放到哪一句（见 [player.md](player.md)）。
